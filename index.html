Documentation

How every feature works

Shortcut

Pinn lives in your keyboard. One combo summons it from anywhere — even over fullscreen apps.

⌘ Shift P
Show / Hide
Press from any app to toggle Pinn. Works over fullscreen, video calls, games — anything.
Ctrl Shift P
Windows shortcut
Same behaviour on Windows. Ctrl replaces Cmd automatically.
Esc
Dismiss
Close Pinn immediately without touching the mouse.

Change the shortcut to any combination inside Settings → Hotkey. Registers system-wide immediately.

Chat

A focused chat interface powered by a fast AI model. No clutter. Just your question and a sharp answer.

Enter
Send message
Send your message and get a response. The AI streams the reply as it's generated.
Shift Enter
New line
Add a line break without sending — useful for multi-line questions or code snippets.
Memory
Persistent context
Pinn retains a memory file at ~/.pinn-memory.json that carries context across sessions.

The AI responds in plain text — no markdown, no asterisks. Clean, readable answers every time.

Screenshot

Capture any part of your screen and send it straight to the AI. Ask about a bug, a design, an error — anything visual.

Camera icon
Start capture (macOS)
Pinn hides itself. Use ⌘ Shift 4 to drag-select any area. Pinn picks up the file from your Desktop automatically.
Camera icon
Start capture (Windows)
Pinn hides, takes a silent snapshot, then shows a dark overlay. Drag to select your area — no permission needed.
Auto attach
Thumbnail preview
A thumbnail appears above the input bar. Type your question and hit Enter — the screenshot is sent automatically.

Images are compressed to 1280px wide before sending to stay within API limits.

Sessions

Every conversation is saved automatically. Switch between them, start fresh, or pick up where you left off.

New chat
Start fresh
Opens a blank conversation. The previous session is saved automatically before switching.
History panel
Browse past chats
Click the sessions icon in the header to open the history panel. Tap any entry to resume that conversation.
Storage
Where sessions live
Sessions are saved as JSON files in ~/.pinn-sessions/. You can read, back up, or delete them directly.

Sessions never leave your device. Nothing is synced to a server. Your conversation history is yours entirely.

Settings

Personalise Pinn to match your style and workflow. Open Settings from the gear icon in the header.

Theme
5 colour themes
Choose from White, Dark, Black, Blue, or Pink. Switches instantly without restarting.
Font size
Small · Medium · Large
Three sizes to keep the interface comfortable at any display scaling.
Hotkey
Custom shortcut
Click the hotkey field and press your combo. Registers system-wide as soon as you save.

All settings are stored in ~/.pinn-settings.json and persist across restarts automatically.

Privacy

Pinn is designed from the ground up to leave no trace. What you type stays on your machine.

OS invisible
No dock, no switcher
macOS: no Dock icon, no Mission Control, no Cmd+Tab. Windows: no taskbar button, no Alt+Tab entry.
Screen share
Invisible to recording
Content protection is enabled at the OS level — Pinn's window does not appear in Zoom, Teams, Meet, OBS, or any screen recorder.
Local only
Nothing leaves your device
Chat history, memory, and settings are stored in plain JSON files on your machine. No account, no cloud sync, no telemetry.

The only outbound connection Pinn makes is to the AI API when you send a message.
